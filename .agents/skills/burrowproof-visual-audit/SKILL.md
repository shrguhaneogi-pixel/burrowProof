# Visual audit

Open the running build and record URL, seed, policy, viewport and tick. Reuse a paused tick when comparing screenshots across layouts.

- Step one tick, then pause. Trace a newly drawn edge, claim ring, delivery pulse or failure marker to its event or current agent state. Compare telemetry with the same tick's event totals.
- Select an agent and compare its view with its recorded local knowledge. Check that unseen regions stay hidden and any enabled evaluator overlay is clearly labeled.
- Exercise changed controls by keyboard and pointer. Inspect focus, touch pan/zoom, chart alternatives and announcements. With reduced motion, check that delivery and failure information remains legible.
- Inspect desktop, tablet and narrow mobile captures. Check the viewport's prominence, label clipping, control reachability, contrast and non-color status cues. For a Lab change, include an incomplete run or failed import when applicable.

Report the exact action and observed outcome for each defect, with the affected viewport and screenshot. Recheck the same seed, tick and interaction after a correction. Distinguish visual inspection from automated assertions.
